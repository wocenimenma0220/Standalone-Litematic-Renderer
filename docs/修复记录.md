# 投影预览 1.3.3

本版本为 **`1.3.3` 功能拓展正式版**（对应标签 `v1.3.3`，正式版 `Latest`），核心新增 **「设置 → 导出模式设置」可视化排版与样式编辑器**（所见即所得实时预览、自由拖拽排版、Photoshop / PowerPoint 风格多轴智能对齐参考线、完整投影元数据字段库、自定义插图、背景样式与自由角度滑块），同步上线 **Minecraft 本地版本目录联动**、**高低版本方块差异检测与双向映射选择弹窗**、**顶部帮助栏** 以及 **Bedrock Ore UI 深度打磨与欢迎窗黄框修复**。

> **升级方式**：
> - **已安装 `1.3.1` / `1.3.2` / `1.3.2.1` 安装版用户**：可直接点击软件右上角 **检查更新** 或输入 `/update` 一键下载约 11 MB 增量补丁自动热替换升级，完整保留 `settings/`、`skins/`、`renders/` 与历史配置。
> - **新用户或希望覆盖更新启动器/关联注册**：下载运行 **`Litematic-Viewer-1.3.3-win-x64-setup.exe`**（免管理员权限），或下载绿色便携版 **`Litematic-Viewer-1.3.3-win-x64.zip`** 解压即用。

## 本次核心新增与改进（1.3.3 · 导出模式拓展）

### 1. 顶部新增「设置 → 导出模式设置…」可视化排版编辑器
在顶部菜单栏新增 **`设置`** 下拉入口（同步整合导出模式设置、跨版本方块映射、MC 本地资源联动与按键设置），在左侧「输出」栏亦提供快捷入口：
- **非模态全工作区停靠 + 可调宽属性栏**：编辑器停靠在顶部 38px 标题栏下方铺满整个应用窗口，打开期间**外层标题栏的最大化、最小化、关闭、拖拽窗口与菜单栏始终可直接点击**，并在编辑器顶栏内置同步的 **`全屏 (F11)`** 开关；中间提供可左右拖动的分隔条（支持 `330px–720px` 自由调宽），右侧属性与字段调节栏更加宽敞清晰。
- **实时所见即所得预览与缩放**：打开投影时按真实三维渲染模型实时刷新展示图，未打开投影时则提供随角度实时旋转的微型 3D 示例方块供排版测试；支持画布 **`－` / `适应` / `＋`** 及 `Ctrl + 滚轮` 缩放查看。
- **Photoshop / PowerPoint 风格多轴智能对齐与等距参考线**：
  - 拖动任意元素时同时触发 X / Y 双轴磁吸与可视化参考线：**品红实线**用于元素间边缘/中线对齐（`同行居中`、`左对齐`、`水平居中`、`右对齐`、`顶/底对齐`、`边缘贴合`，可贯穿多个匹配元素）；**青蓝双端标尺**用于检测同行或同列的**等距间距**（如 `14px`）与居中平分；**翠绿虚线**用于画布中线（50%）、三分线、四分线、安全边距与各三维视口边线/中线对齐。
  - 支持工具栏一键开关 **`智能对齐`** 与常驻 **`参考网格`**；拖动时按住 `Alt` 临时取消磁吸自由微调，选中元素后支持 **方向键 1px / `Shift + 方向键` 5px** 精细微调。

### 2. 投影全量元信息暴露、自由排版、插图、背景与角度定制
- **完整暴露 `.litematic` / `.nbt` / `.schem` 全部保存信息（共 22 项可选字段）**：
  - 后端新增解析并暴露：`创建时间 (TimeCreated)`、`修改时间 (TimeModified)`、`子版本 (SubVersion)`、`源格式 (SourceFormat)`、`实体总数`、`方块实体/容器总数`、`方块/流体计划刻数`、`方块种类数与调色板状态数`、`文件名`、`文件大小`、`当前渲染角度`、`当前材质包摘要` 以及 Litematica 内嵌缩略图 `PreviewImageData`（连同原有名称、作者、说明、包围盒尺寸、非空气方块数、总体积、子区域数与子区域列表、投影版本、游戏版本、数据版本 ID、生成时间）。
  - 每一行信息均可一键勾选加入画布并**独立鼠标拖动位置**，可自定义标签名、前/后缀或覆盖文本、显示风格（纯文本 / 绿条信息行 / 胶囊标签 / 独立信息卡）、字号、粗体、对齐方式、最大宽度、文字色/标签色/装饰条色/底色/边框色，并支持 **`＋ 添加自定义文字`** 与 **`整齐排列底部信息`**（1/2/3 列自动网格）。
- **自定义左上角图标与自由插入图片**：
  - 左上角图标支持在 **软件默认图标 / 投影内嵌缩略图 / 本地上传图片** 间切换；支持通过 **`＋ 插入图片…`** 导入任意多张本地 PNG / JPG / WebP / GIF（持久化保存在 `settings/sheet-assets/`），独立拖动位置、调节尺寸、透明度、图层顺序与像素锐化。
- **背景样式与导出角度全视觉控制**：
  - 支持整图 **纯色 / 双色渐变 / 透明背景 PNG / 自定义背景图片**（内置常用 Ore UI 快捷色板），并可单独调节顶栏底色与装饰彩条、三维视口卡片填充模式（径向暗角光晕 / 纯色 / 透明融入背景）与边框色、底部信息背板颜色。
  - 支持 **`双视角（左右并排）` / `双视角（上下叠放）` / `单视角（居中大图）`** 排版切换，视图 1 与视图 2 均支持 15 套标准预设、`当前交互视角` 与 **水平旋转 `0°–360°` / 俯仰角 `-89°–89°` 滑块**自由定制角度，无需输入任何指令。

### 3. Minecraft 本地版本目录联动（MC联动）
- 顶部菜单栏新增 **`MC联动`**（同时支持「文件 → 关联 MC 版本文件夹…」与材质包栏快捷入口）：支持导入任意版本隔离目录（如 `.minecraft\versions\1.21.11-Fabric 0.18.4`）或 `.minecraft` 根目录，强制校验 `resourcepacks` 文件夹存在。
- 自动扫描版本 JSON、客户端 JAR（获取精确版本、`DataVersion` 与目标版方块表）、加载器信息、`options.txt`（识别游戏内已启用材质包及优先级）、`mods`（检测 Litematica）与 `schematics` 文件夹；支持一键同步已启用材质包、可选挂载该版本客户端 JAR 作为原版基础层，以及在联动面板内搜索并一键打开渲染 `schematics` 中的投影。

### 4. 高低版本方块差异检测与双向映射弹窗
- 渲染投影时自动比对投影 `MinecraftDataVersion`、方块调色板与目标版本（未联动默认为 `26.3`，联动后自动切换为所选 MC 版本），智能识别 `chain ↔ iron_chain`（1.21.9+）、`grass / tallgrass ↔ short_grass`（1.20.3+）、`grass_path ↔ dirt_path`（1.17+）、`sign / wall_sign ↔ oak_sign / oak_wall_sign`（1.14+）、`cauldron[level=1..3] ↔ water_cauldron`（1.17+）、墙体连接属性 `true/false ↔ low/none`（1.16+）、1.13 扁平化前旧版方块，以及目标低版本不支持的高版本方块提示。
- 发现差异时弹出可视化选择窗口，用户可逐项或一键切换 **`更改映射`** 与 **`按旧版保留`**（旧版模式保留原始 ID 并兼容渲染/草色染色/材料清单图标回退）并立即重渲染，支持「记住本次选择」及随时重调。

### 5. 顶部「帮助」栏、Bedrock Ore UI 视觉打磨与欢迎窗修复
- **顶部新增「帮助」弹窗**：集中介绍 MC 本地目录联动规则、常见高低版本差异与映射策略区别、导出模式可视化排版与常用快捷键。
- **修复欢迎窗链接黄框**：消除 `#welcomeDialog` 每次打开时 `<a id="authorLink">网页链接</a>` 自动获焦出现的默认黄色聚焦外框，同时保留键盘 Tab 导航的清晰白色焦点提示。
- **Ore UI 视觉统一打磨**：修复未定义样式变量造成的按钮与分组缺边问题；强化深炭/石砖分阶、锐利像素边框与凹凸斜面质感；为所有弹窗加入深色 Ore UI 顶栏条，升级祖母绿复选框、滑块滑轨与方块滚动条，并统一顶部菜单按钮观感。
