## 本次核心新增与修复（1.3.4 · PBR 材质包兼容 & 全语言 Unicode）

### 1. 光影 PBR 材质包兼容与超大图集 GPU 保护
- **自动过滤光影 PBR 辅助贴图**：加载外部资源包时自动过滤 `textures/block/` 与 `textures/entity/` 下的 LabPBR 法线与高光贴图（`*_n.png`、`*_s.png`），大幅缩减高清材质包图集尺寸，彻底解决加载 PBR 材质包时因纹理总尺寸超出显卡上限导致画面全黑的问题。
- **图集自适应排版与降采样兜底**：优化 2 次幂纹理图集货架布局，当极端超高分辨率资源包仍超出 GPU 单边纹理上限（默认 `16384`）时自动分级降采样至安全尺寸；同步放宽高清材质包磁盘缓存体积限制并升级缓存指纹（`resource-images-v2`），二次加载可直接命中缓存。
- **WebGL 上传安全校验**：前端上传图集前主动检测 `gl.MAX_TEXTURE_SIZE`（超限时经离屏画布最近邻降采样），并在 `gl.texImage2D` 后检查 `gl.getError()`，避免纹理上传失败时静默呈现全黑画面。

### 2. 告示牌全语言 Unicode、富文本样式与材质包字体合并
- **按需惰性解码全量 Unicode**：重写 `Unihex` 字库加载逻辑为按需索引解码（零启动内存膨胀），全面开放除控制字符外的 Unicode 字符渲染，告示牌与文字展示实体原生支持中文、日文假名、韩文谚文、西里尔字母、希腊/拉丁扩展、常用符号与 Emoji 等多语种文本（暂不含阿拉伯/希伯来语 RTL 复杂排版）。
- **资源包字体栈合并与带注释 JSON 兼容**：
  - 使用完整资源包栈（`getResourceStack`）合并 `font/*.json` 提供者，自定义图标字体包与原版/Unifont 字库可并存生效，不再因上层资源包仅声明私有区图标而导致普通文字消失。
  - JSON 解析器支持跳过 UTF-8 BOM、`//` 单行注释与 `/* */` 块注释，兼容带注释的材质包字体定义；修复 bitmap 字体 `ascent` 基线对齐。
- **完整富文本组件与格式化代码支持**：支持解析并剥离 `§` 格式化代码，正确渲染按片段独立着色（命名色与 `#RRGGBB`）、样式继承、粗体、斜体、下划线、删除线、`translate` + `with` 翻译占位符（内置 `en_us` / `zh_cn` 语言表）、`keybind` 以及 `minecraft:alt` 等自定义字体。

### 3. 方块模型旋转、`uvlock` 修复与 11 个缺失原版方块补全
- **多轴欧拉旋转与复合 `uvlock` 修复**：支持 MC 26.x 模型元素的多轴欧拉旋转（`{"x","y","z"}`，修复旋转悬挂告示牌锁链等部件错位）；将 `uvlock` 重写为三维 UV 基底投影，修复同时包含 X/Y/Z 旋转（如倒置楼梯）时的贴图锁定偏差。
- **补全 11 个原版方块渲染**：
  - **8 种铜箱子**（`copper_chest`、`exposed_copper_chest`、`weathered_copper_chest`、`oxidized_copper_chest` 及全部 4 种涂蜡变种），完整支持单箱与双箱拼接。
  - **末地传送门**（`end_portal`）与 **末地折跃门**（`end_gateway`），提供程序合成星空纹理。
  - **移动中的活塞方块**（`moving_piston`），按方块实体 NBT 中的 `blockState`、`facing`、`progress` 静态还原位移中的方块及群系着色。

### 4. 实体方块群系着色修复与 1.21.4+ 物品模型体系
- **实体方块模型接入群系染色**：掉落草方块、矿车内展示草方块、方块展示实体与末影人手捧草方块等实体内方块模型全面应用 `BlockTints`，修复灰白失色问题。
- **1.21.4+ 物品模型定义与多层染色合成**：支持解析 `items/*.json` 中的 `model`、`composite`、`condition`、`select`、`range_dispatch` 与 `special` 定义，并支持多层 2D 物品贴图（`layer0..N`）与染色组件合成（药水、染色皮革护甲、烟花之星、草/树叶、地图等在展示框、展示实体与手持状态下均准确还原颜色与样式）。

### 5. 新增 7 种装饰/展示实体与 29 种常见原版生物实体
- **装饰与展示实体（7 种）**：
  - `armor_stand`（支持各部位姿态、手臂/底板开关及隐形盔甲架穿戴护甲/头颅/手持物品）
  - `painting`（内置全部 51 种原版画作方块尺寸表并兼容高清材质包）
  - `end_crystal`、`leash_knot`
  - `block_display`、`item_display`、`text_display`（支持变换矩阵/四元数/轴角旋转、自定义光照、多语言富文本、背景透明度与阴影）
- **常见原版生物实体（29 种）**：
  - **村落与功能生物**：`villager`（支持群系/职业/等级外衣叠加）、`zombie_villager`、`wandering_trader`、`shulker`（支持 16 色、附着面与探头开盖）、`allay`、`copper_golem`（支持 4 种氧化状态与发光眼）。
  - **常见敌对与 Boss 生物**：`zombie`、`husk`、`drowned`（含外层）、`skeleton`、`stray`、`wither_skeleton`、`bogged`（含苔藓外层）、`zombified_piglin`、`piglin_brute`、`witch`、`pillager`、`vindicator`、`evoker`、`creeper`、`enderman`（含发光眼与手捧方块）、`slime`、`magma_cube`（适配 26.3 新版 `64×64` 贴图布局与旧版 `64×32` 回退）、`blaze`、`guardian`、`elder_guardian`（含 12 根尖刺）、`ghast`、`happy_ghast`、`warden`（含独立无冲突发光层）。
  - 同步补充旧版 PascalCase 实体 ID 兼容映射（如 `ArmorStand`、`Painting`、`EnderCrystal`、`Villager`、`Zombie` 等）。
