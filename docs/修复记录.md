# 投影预览 1.3.2.1

本版本为 **`1.3.2.1` 维护修复版**（对应标签 `v1.3.2.1`，正式版 `Latest`），重点修复 Windows 安装/卸载注册表清理归属判断、测试沙箱隔离、文件关联刷新及增量补丁元数据同步问题；完整包含 **`1.3.2` 单实例打开与四段版本号兼容** 及 **`1.3.1` 全套工作流升级**。

> **升级建议**：
> - 如果你当前在 Windows「已安装的应用」里看不到 `投影预览`，或双击 `.litematic` 无法默认打开（或希望更新根目录的新版启动器与 `卸载投影预览.exe`），推荐直接下载运行 **`Litematic-Viewer-1.3.2.1-win-x64-setup.exe`** 覆盖安装到原目录（会完整保留 `settings/`、`skins/`、`renders/` 与缓存）。
> - 如果你本机的系统注册与关联正常，已安装 `1.3.1` / `1.3.2` 安装版的用户也可直接在软件内点击 **检查更新** 或输入 `/update` 一键下载增量补丁升级（更新 `bin/`、`webapp/` 与内置资产）。

## 本次修复详情（1.3.2.1 · 安装器归属保护、关联增强与沙箱隔离）

### 1. 安装/卸载多目录归属保护与 `--reg-root` 注册表沙箱隔离（`Setup.cs`）
- **卸载归属核对（修复跨目录/旧版本卸载误伤现役安装）**：`卸载投影预览.exe` 执行 `RunUninstall` 时，在清理以下全局项前会先逐一比对路径是否归属于当前安装目录：
  - `HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\LiteKindaProjectionPreview` 的 `InstallLocation` / `UninstallString`；
  - `Software\Classes\LiteKinda.ProjectionPreview`、`Applications\投影预览.exe`、`Capabilities`、`RegisteredApplications` 与 `.litematic / .nbt / .schem` 关联默认值及 `OpenWithProgids`；
  - 桌面 `投影预览.lnk` 与「开始」菜单 `投影预览\` 快捷方式目标路径（`TargetPath`）。
  - 只有在系统注册表/快捷方式确切指向当前正在卸载的目录时才执行清理，彻底杜绝多路径安装后清理旧目录导致现役安装“在应用列表消失、双击 `.litematic` 失效”的问题。
- **构建与测试注册表沙箱隔离（`--reg-root`）**：安装向导新增 `--reg-root Software\LiteKindaTest\...` 测试沙箱参数，回归测试 `tools/verify/release/installer-updater-regression.cjs` 全面改在临时隔离子键内验证注册表写入、多目录保护、修复与卸载流程，不再改动本机真实 `Uninstall`、`Classes` 或桌面快捷方式。

### 2. Windows 10/11 应用列表展示与默认文件关联增强（`Setup.cs`）
- **应用列表元数据完善**：写入标准 `,0` 图标索引与安装大小 `EstimatedSize`（KB `DWORD`），使 Windows 10/11「设置 → 应用 → 安装的应用」正确显示图标与体积。
- **完整 Win32 用户态文件关联 + 即时刷新**：除注册 `LiteKinda.ProjectionPreview` ProgID 与 `.litematic / .nbt / .schem` 扩展名外，同步注册：
  - `HKCU\Software\Classes\Applications\投影预览.exe`（`FriendlyAppName`、`DefaultIcon`、`SupportedTypes` 与命令行）；
  - 各扩展名下的 `OpenWithProgids`；
  - `Software\LiteKinda\ProjectionPreview\Capabilities` 与 `HKCU\Software\RegisteredApplications`；
  - 安装、修复或卸载完成后立即调用 `SHChangeNotify(SHCNE_ASSOCCHANGED)`，通知 Windows 资源管理器即时刷新 `.litematic` 图标与默认打开方式。
- **新增 `--repair` 修复模式**：可通过 `setup.exe --repair --dir "<安装目录>"` 或 `卸载投影预览.exe --repair` 在不覆盖用户设置的前提下重新修复应用列表项、文件关联与快捷方式。

### 3. 补丁元数据同步与中文目录日志兼容性（`Launcher.cs`）
- **补丁版本字段完整同步**：`投影预览.exe --apply-update` 完成热替换后，同步更新 `install-manifest.json` 的 `installedVersion` 与 `displayVersion`，并在刷新卸载项 `DisplayVersion` 前核对 `InstallLocation` 归属。
- **GUI 启动器日志 UTF-8 编码对齐**：启动 Electron 时显式指定 `StandardOutputEncoding` / `StandardErrorEncoding` 为 `UTF-8`，避免含中文路径或中文报错信息写入 `logs/launcher.log` 时变成乱码。
- **中文目录实测验证**：在简体中文 Windows（`GBK / 936` 代码页）下已实测 CLI 与完整 Electron + Java + WebGL 流程均可在中文目录正常运行；若在英文等非 GBK 系统区域环境下使用，因内置 `runtime/bin/java.exe` 未声明 UTF-8 代码页清单，仍推荐使用纯英文安装路径。

## 包含 `1.3.2` / `1.3.1` 全部既有特性
1. **外部打开单实例复用与四段版本号支持**：运行中双击关联文件或拖入新投影不再新开第二个窗口，直接前置原窗口即时切换加载；完美兼容 `1.3.2.1` 等四段热修版本号比较与 `no-store` 清单拉取。
2. **Bedrock Ore UI 深色工作区、无边框标题栏与微时序红石排查**：自定义最小化/最大化/关闭标题栏、`appearance: base-select` 下拉菜单、三维「更改投影」抽屉、材料/容器分离统计、`/ & //` 一二级指令及二维「侧视 / 俯视」微时序沙盒。
3. **GPU 极速导出与纯粹「导出模式」**：离屏 FBO 秒出 PNG / 360° GIF、自适应双视角展示卡（支持 15 套标准预设视角、滚轮缩放查看台、一键按当前视角重导及自动写入系统剪贴板）。
