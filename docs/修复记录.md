# 投影预览 1.3.0

本版本为 `1.3.0` 正式版，对应标签 `v1.3.0`。在整合 `1.3.0-beta` 与 `1.3.0-beta-v2` 全部渲染引擎、三维编辑、高分辨率导出与二维微时序改进的基础上，正式上线 **Bedrock Ore UI / Minecraft.net 深色像素风界面重制**。

---

## 本次更新详情（1.3.0 · UI 更新与功能汇总）

### 1. Bedrock Ore UI / Minecraft.net 界面风格重制（UI 更新）
- **中性深灰石质底色与视口棋盘格**：全局替换原偏蓝深色方案，采用 `#18181a / #1b1b1e / #222327` 深炭灰卡片层级与中性暗灰视口棋盘格，提升红石、透明方块与建筑模型色彩对比度。
- **MC 官网绿立体按钮与点击下沉反馈**：全界面引入 `2px` 硬朗切角与 `inset` 顶部高光 + 底部硬阴影立体按钮（`:active` 点击下沉）；主操作按钮采用经典 Minecraft 绿（`#3c8527`），二维搭建与选中态采用青金石蓝（`#2c6dc2`）。
- **顶栏版本徽章、16×16 像素图标与实时 HUD**：顶栏拆分独立矩形版本徽章（`1.3.0`）；左侧 11 个功能面板标题接入原版 16×16 像素图标（箱子、红石粉、书与笔、Steve 头像等）；视口左上角新增实时 WebGL2 / 视角（`Yaw / Pitch / Zoom`）/ 模型统计悬浮 HUD。
- **全工作区视觉统一**：同步重制材料清单弹窗、欢迎与快捷键弹窗、三维“更改投影”抽屉与 36 格背包/漫游快捷栏、二维搭建画布与微时序/容器背包弹窗。

### 2. 草方块、树叶染色与跨版本方块兼容（1.3.0-beta-v2 延续）
- **按贴图染色槽位精确着色**：接入 `grass.png`、`foliage.png`、`dry_foliage.png` 色图加载与远景总览一致化染色；兼容常见跨版本重命名方块、旧版状态属性及缺失模型的兜底占位渲染。

### 3. 超高分辨率与「无损」流式 PNG 导出
- 导出分辨率扩展至 `8192～81920` 并新增 **「无损（贴图最高清晰）」** 模式，配合 `StreamingPngWriter` 低内存分条带流式编码与后台导出队列控制；GIF 动画统一保持最高 `4096 × 4096` 安全边界。

### 4. 三维编辑、分块流式预览与二维微时序
- 完整包含 `1.3.0` 系列引入的三维“更改投影”编辑与调试棒、36 格背包、分块流式加载与可配置场景缓存、以及包含活塞/容器/铁轨矿车/TNT 爆炸/基础流体的二维搭建微时序测试环境。

## 下载与使用

1. 下载附件中的 **`Litematic-Viewer-1.3.0-win-x64.zip`**（适用 Windows 10/11 64 位，内置 Java 与 Electron 运行时，无需额外配置环境）。
2. 完整解压到可写目录（保留包内 `bin`、`runtime`、`assets`、`webapp` 等目录结构），双击 **`投影预览.exe`** 即可运行。
3. 可通过附件 **`SHA256SUMS.txt`** 校验压缩包与说明文件哈希完整性。
