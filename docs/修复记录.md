# 投影预览 1.3.2

本版本为 **`1.3.2` 正式版**（对应标签 `v1.3.2`），整合 **`1.3.1.1` 外部单实例打开与四段版本号修复**，并以三段正式版本号发布，确保已安装 **`1.3.1`** 的用户可直接通过应用内增量补丁一键升级，无需重新下载完整安装包。

---

## 本次更新详情（1.3.2 · 单实例打开与更新器完善）

### 1. 外部打开投影单实例复用（不再新开第二个窗口）
- **单实例窗口复用**：主进程启用 `app.requestSingleInstanceLock()` 与 `second-instance` 事件调度。已有窗口运行时，外部再通过文件关联双击、拖拽到 `投影预览.exe` 或命令行传入 `.litematic / .nbt / .schem` 文件时，不再启动第二个桌面窗口与第二个 Java 渲染进程，而是直接唤醒并前置原窗口加载新投影；第二个拉起进程安全退出并跳过缓存清理，防止影响运行中实例的渲染缓存。
- **运行期即时接管 `app:openFile`**：渲染进程补充运行期即时打开通路（无论当前处于 3D 交互预览或纯粹**导出模式**，均在当前窗口即时切换或直接生成双视角展示图并复制到剪贴板）。

### 2. 更新器稳定性与版本号兼容
- 修复 `version.cjs` 与应用内更新器 `updater.js` 对四段修订版本号（如 `1.3.1.1`）的解析与版本比较逻辑（不再把第 4 段数字误判为预发布后缀），并对远程清单请求禁用缓存（`cache: 'no-store'`）。

## 完整包含 `1.3.1` 全部功能改进
1. **无边框窗口与 Ore UI 下拉控件**：自定义顶部窗口控制键与 `appearance: base-select` 无蓝框下拉面板。
2. **GPU 极速导出与多核 CPU 编码**：离屏 WebGL PNG / 360° GIF 导出切换与软件管线提速。
3. **「导出模式」与双视角展示卡**：WikiRenderer / KCL 15 套标准预设视角、自适应尺寸与分辨率联动、滚轮指针缩放与拖动平移、自定义保存目录与自动剪贴板复制、切回交互预览与背景遮罩修复。
4. **一级（`/`）与二级（`//`）指令系统**：支持 Tab 补全、历史回溯及选区与批量编辑。
5. **`--dev` 热渲染开发流**、**Windows 单文件安装版（`setup.exe`）**、**安装版增量补丁自动更新 / 便携版引导下载双轨机制** 与 GitHub Actions 自动发布流水线。

## 下载与升级说明

- **已安装 `1.3.1`（安装版）的用户**：无需重新下载，打开软件点击顶部栏「检查更新」或输入 `/update` 即可自动识别 `1.3.2` 并下载约 **10.9 MB** 增量补丁包，重启即完成更新并保留全部个人设置。
- **首次安装 / 重装 · Windows 安装版**：下载附件 **`Litematic-Viewer-1.3.2-win-x64-setup.exe`**，双击即可安装（无需管理员权限），后续版本均支持应用内增量补丁更新。
- **绿色免安装 · 便携 ZIP 版**：下载 **`Litematic-Viewer-1.3.2-win-x64.zip`** 完整解压至可写目录后双击 `投影预览.exe` 运行。
- **增量补丁与校验**：**`Litematic-Viewer-1.3.2-win-x64-patch.zip`** 与 **`latest.json`** 供自动更新器使用；全部文件可在 **`SHA256SUMS.txt`** 核对 `SHA-256` 哈希。
