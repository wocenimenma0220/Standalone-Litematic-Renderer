# 投影预览 1.3.1

本版本为 **`1.3.1` 正式版**（对应标签 `v1.3.1`，提交说明：`ui补充和工作流完善`）。在 `1.3.0` Ore UI 深色像素风格的基础上，全面补充无边框窗口、自绘下拉控件、GPU 极速导出、纯导出模式双视角展示卡、一/二级指令体系、`--dev` 热渲染开发流，并正式上线 **Windows 安装版（`setup.exe`）与双轨 GitHub 自动更新推送机制**。

---

## 本次更新详情（1.3.1 · UI 补充与工作流完善）

### 1. 无边框窗口与 Ore UI 控件细节打磨
- **移除原生白色系统标题栏**：升级为无边框窗口（`frame: false`），将标题、版本徽章、应用菜单与检查更新入口收拢到顶部自定义标题栏，并在右上角内嵌统一像素风「最小化 / 最大化还原 / 关闭」窗口控制按键（含最大/还原态图标切换）。
- **彻底去除系统蓝色下拉框与蓝边**：利用 Chromium 130+（Electron 44）原生 `appearance: base-select` 与 `::picker(select)` 特性，将工具栏「导出 / 背景」及侧栏全部下拉菜单重构为 Ore UI 深灰切角面板（完全消除系统原生高亮蓝框、蓝色聚焦描边与弹出白底割裂感）。

### 2. GPU 极速导出与多核 CPU 编码优化
- **新增「GPU 极速 / CPU 精确」导出切换**：工具栏「导出」下拉菜单默认开启 **GPU 极速**，直接复用已构建的 WebGL 几何与贴图离屏 FBO 出图（毫秒级导出透明/背景 PNG，并流式采集 480 帧结合后台 Java 多核 LZW 并行完成 360° GIF 导出）。
- **CPU 精确导出同步提速**：针对无损自适应（`lossless`）或 `8192～81920` 超高分辨率与大投影分块导出保留 **CPU 精确** 管线，并行优化 `GifWriter` 帧编码效率。

### 3. 全新「导出模式」与双视角展示卡系统（含 WikiRenderer / KCL 预设视角）
- **工具栏「导出模式」开关**：开启后软件进入纯粹导出模式，**拖入或打开 `.litematic / .nbt / .schem` 文件即直接生成双视角展示图 PNG，不再挂载交互式 3D 渲染画布**，适合批量快速出图。
- **自适应双视角展示卡排版**：参考 KCL 信息卡结构并采用启动器 Ore UI 视觉重构：
  - 顶部显示启动器图标、名称与模型长宽高尺寸徽章；
  - 中部左右两张自适应尺寸的透明通道投影展示面板（完整保留信息且随建筑长宽比与侧栏 `#size` 分辨率设置动态缩放）；
  - 底部保留作者、游戏版本、投影版本、方块/区域统计与生成时间；
  - 默认自动保存 PNG 至**投影同目录**（可在左侧「默认位置」自定义保存文件夹），并默认通过 Chromium `ClipboardItem` 自动复制到系统剪贴板，方便直接在 QQ / 微信 / Discord 等工具中粘贴发送。
- **内置 15 套标准预设视角**：整合 `WikiRenderer-26.3` / `KCL` 预设角度库（等轴测、二轴测正反视角、东南西北四向及顶/底视图等），除默认双视角外支持在左侧与三维视图下拉框自由切换、一键顺时针旋转 90° 或俯仰角切换，并支持「按当前视角重导」。
- **展示图预览交互与 Bug 修复**：
  - 修复展示图面板内部「切换为交互预览」等按钮的指针捕获冲突，确保一键稳定切回 3D 交互；
  - 强制隐藏导出模式下背景画布并消除半透明底色渗透，防止拖入/重导时背后仍渲染出 3D 模型；
  - 为生成的展示图预览窗新增**以鼠标位置为中心的滚轮缩放（0.5× – 12×）、鼠标按住拖动平移、双击重置适应、以及「`－ / 适应 / ＋ / 1:1`」缩放条**，再也不受后台 3D 缩放干扰。

### 4. 一级（`/`）与二级（`//`）指令系统扩容
- **Tab 自动补全、上下方向键历史与错误命令行保留**。
- **一级全局指令（`/`）**：新增/完善 `/help`、`/commands`、`/pos`、`/tp`、`/view`、`/zoom`、`/fly`、`/vd`、`/search`、`/clearsearch`、`/locate`、`/bg`、`/light`、`/layer`、`/tool`、`/export`、`/sheet`、`/sheetmode`、`/materials`、`/fullscreen`、`/sidebar`、`/console`、`/reload`、`/stop`、`/update`。
- **二级选区与批量编辑指令（`//`）**：支持 `//select`、`//pos1`、`//pos2`、`//desel`、`//expand`、`//contract`、`//shift`、`//outset`、`//inset`、`//size`、`//count`、`//distr`、`//set`、`//replace`、`//undo`、`//redo`（均支持中英文方块名、方块 ID 与状态属性 `[facing=north,...]`）。

### 5. `--dev` 轻量热渲染工作流（开发体验提升）
- 启动脚本新增 `--dev` / `LITEMATIC_HOT_RELOAD=1` 支持：修改 `webapp/renderer/*.css` 自动原地热替换样式表并保持当前已加载的 3D WebGL 模型现场不丢失；修改 `.html / .js` 自动防抖刷新渲染窗口。

### 6. Windows 安装版（`setup.exe`）、增量补丁与自动化发布流水线
- **全新单文件 Windows 安装版（`Litematic-Viewer-1.3.1-win-x64-setup.exe`）**：图形化安装向导，默认安装至用户可写目录 `%LocalAppData%\Programs\投影预览`（免管理员权限），可选创建桌面快捷方式、开始菜单快捷方式、关联 `.litematic / .nbt / .schem` 文件双击打开，并在 Windows「应用和功能 / 控制面板」注册规范卸载入口（`卸载投影预览.exe`）。
- **双轨 GitHub 自动更新区分（安装版 vs 便携 ZIP 版）**：
  - **安装版（方式二 · 自动增量补丁）**：启动或点击顶部栏「检查更新」/ `/update` 读取 GitHub Release 的 `latest.json`（绕开 API IP 限流）。若 Electron/Java 运行时未变更，仅需下载约 10–11 MB 的增量补丁包，经 **`SHA-256` 严格校验与路径安全解包**后，在退出重启时由原生启动器 `投影预览.exe` 自动完成备份、热替换并保持用户设置与导出目录完整（失败自动回滚）；若底层运行时升级则自动引导运行新版安装程序。
  - **正常便携 ZIP 版（方式一 · 检测并引导下载）**：检测到新版本后弹窗展示更新内容并引导用户前往 GitHub 下载新版 ZIP 压缩包（或改下安装版），不修改便携目录文件。
- **GitHub Actions CI/CD 流水线（`release.yml`）**：支持推送 `v*` 标签自动编译引擎、构建全量便携 ZIP、轻量补丁包、Windows 安装包 `setup.exe`、`latest.json` 及 `SHA256SUMS` 并发布 Release。

## 下载与安装说明

> 本次共提供两种运行形态与增量补丁文件，按需选择一种即可：

1. **推荐 · Windows 安装版：`Litematic-Viewer-1.3.1-win-x64-setup.exe`**
   - 双击即可引导安装，自带 Java 与 Electron 运行时，支持桌面/开始菜单快捷方式、双击投影文件直接预览、控制面板规范卸载，以及**后续新版本应用内增量补丁自动更新**。
2. **绿色免安装 · 便携 ZIP 版：`Litematic-Viewer-1.3.1-win-x64.zip`**
   - 完整解压到可写目录（保留 `bin`、`runtime`、`assets`、`webapp` 目录结构）后双击 `投影预览.exe` 启动；内置版本检测与新版 ZIP 下载引导。
3. **增量代码补丁包：`Litematic-Viewer-1.3.1-win-x64-patch.zip`（约 11 MB）与 `latest.json`**
   - 供安装版软件内置更新器校验与增量升级使用，通常无需手动单独下载。
4. 全部附件均可在 **`SHA256SUMS.txt`** 中核对 `SHA-256` 哈希校验值。
