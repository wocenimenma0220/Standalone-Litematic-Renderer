# 投影预览 1.3.1.1

本版本为 **`1.3.1.1` 热修发布**（对应标签 `v1.3.1.1`，提交说明：`修个小bug`），修复外部双击/命令行再次打开投影文件时重复弹出新窗口的问题，并完整保留 `1.3.1` 全部功能。

---

## 本次更新详情（1.3.1.1 · 问题修复与版本号兼容）

### 1. 外部打开投影单实例复用（不再新开第二个窗口）
- **单实例窗口复用**：主进程启用 `app.requestSingleInstanceLock()` 与 `second-instance` 事件调度。已有窗口运行时，外部再通过文件关联双击、拖拽到 `投影预览.exe` 或命令行传入 `.litematic / .nbt / .schem` 文件时，不再启动第二个桌面窗口与第二个 Java 渲染进程，而是直接唤醒并前置原窗口加载新投影；第二个拉起进程安全退出并避免触发缓存误清理。
- **运行期即时接管 `app:openFile`**：渲染进程补充运行期即时打开通路（无论当前处于 3D 交互预览或纯粹**导出模式**，均在当前窗口即时切换或直接生成双视角展示图并复制到剪贴板）。

### 2. 四段修订版本号兼容
- 修复 `version.cjs` 与应用内更新检查器 `updater.js` 对 `1.3.1.1` 这类四段修订版本号的解析、Windows 程序集版本推导与版本大小比较逻辑。

## 延续包含 `1.3.1` 完整更新内容
1. **无边框窗口与 Ore UI 下拉控件**：自定义顶部窗口控制键与 `appearance: base-select` 无蓝框下拉面板。
2. **GPU 极速导出与多核 CPU 编码**：离屏 WebGL PNG / 360° GIF 导出切换及软件管线并提速。
3. **「导出模式」与双视角展示卡**：WikiRenderer / KCL 15 套标准预设视角、自适应尺寸与分辨率联动、滚轮指针缩放与拖动平移、自定义保存目录与自动剪贴板复制、切回交互预览与背景遮罩修复。
4. **一级（`/`）与二级（`//`）指令系统**：支持 Tab 补全、历史回溯及选区与批量编辑。
5. **`--dev` 热渲染开发流**、**Windows 单文件安装版（`setup.exe`）**、**安装版增量补丁自动更新 / 便携版引导下载双轨机制** 与 GitHub Actions 自动发布流水线。

1. **推荐 · Windows 安装版：`Litematic-Viewer-1.3.1.1-win-x64-setup.exe`**
   - 双击即可引导安装（无需管理员权限），自带 Java 与 Electron 运行时，支持快捷方式、双击 `.litematic / .nbt / .schem` 单窗口直接预览、控制面板卸载，以及**后续新版本应用内增量补丁自动更新**。
