# 投影预览 1.3.0-beta-v2（1.3.0βv2）

本版本为 `1.3.0` 系列第二次预发布测试版（Pre-release），对应标签 `v1.3.0-beta-v2`。主要解决跨版本投影中草方块与部分方块不渲染或错色的问题，并大幅扩展高分辨率与「无损」导出能力。

---

## 本次更新详情

### 1. 草方块、树叶与远景总览染色修复
- **按贴图染色槽位精确着色**：在 `Colormaps` 中接入 `textures/colormap/grass.png`、`foliage.png`、`dry_foliage.png` 加载与缓存序列化；`BlockTints` 严格依据模型 `tintindex` 触发染色——草方块顶面与侧面草皮覆盖层按资源包色图着色，泥土底面保持原色，避免整体发灰或异常雪白，并兼容矮草、高草、蕨类、树叶、藤蔓、睡莲、水等方块与自定义资源包纹理。
- **远距离纯色总览一致化**：修复 `OverviewMesh` 对草方块等方块提取代表色时误取通用粒子贴图（如 `minecraft:block/dirt`）的问题；改为优先读取顶面贴图并叠加 `BlockTints` 染色，使远景总览色块与近景加载后的真实模型颜色保持一致。

### 2. 高低版本方块映射与未知方块兜底
- **跨版本方块重命名映射**：在 `BlockRegistry` 补充常见新旧版本名称映射，覆盖 `minecraft:chain -> minecraft:iron_chain`、`minecraft:grass / tallgrass -> minecraft:short_grass`、`grass_path -> dirt_path`，以及旧版门、栅栏、栅栏门、楼梯、台阶、羊毛、陶瓦、旗帜、头颅、刷怪笼、工作台等历史 ID，映射后再按当前资源包属性表解析状态。
- **旧版方块状态属性适配**：在 `LitematicaSchematic` 适配含水炼药锅（`minecraft:cauldron[level=1..3]` -> `minecraft:water_cauldron`）、旧版墙体连接布尔值（`true/false` -> `low/none`），以及 `lit_*`、`powered_*`、`double_*_slab` 等隐含属性状态。
- **未知方块实体兜底模型**：在 `ModelBaker` 为缺失模型定义的方块补充 `minecraft:block/missingno` 粉黑棋盘格立方体烘焙逻辑，遇上未兼容的冷门模组或超新版本方块时仍保持可见占位，不再直接隐形漏块。

### 3. 超高分辨率（8192～81920）与「无损」流式导出
- **更多导出分辨率档位**：导出面板分辨率下拉框在 `512～4096` 基础上扩展 `8192`、`16384`、`24576`、`32768`、`40960`、`49152`、`57344`、`65536`、`73728`、`81920` 共 10 档高分选项，并在底部新增 **「无损（贴图最高清晰）」** 模式。
- **贴图清晰上限自动定尺**：选择「无损」时，`SchematicRenderer` 会依据当前选区或整体模型包围盒、视角与资源包最大贴图密度自动计算清晰范围内的最大导出尺寸（单边最高支持 `81920` 像素），兼顾透明背景与纯色/图片背景。
- **低内存流式 PNG 编码**：新增 `StreamingPngWriter` 按条带分块软光栅并增量压缩输出 PNG `IDAT` 数据块再原子落盘，支持超大尺寸和无损截图稳定完成导出、汇报进度及随时取消，避免整帧占用过多内存。
- **GIF 安全上限保护**：旋转 GIF 因体积与编码开销限制，UI 与后端统一保持 `4096 × 4096` 最大边界；选择更高分辨率或「无损」后点击导出 GIF 会自动按 `4096 × 4096` 执行并记录提示。

### 4. 界面与稳定性延续改进（基于 1.3.0-beta）
- 保持深色界面主题、分块流式网格加载、后台导出任务队列独立控制以及可配置持久缓存等 `1.3.0-beta` 基础改进。
- 新增 `GrassAndVersionRegression`、`LosslessAndHighResRegression` Java 回归测试，并扩展桌面端 `transparent-export-ui.cjs` 验证高分选项清单与后台无损透明导出流程。

## 下载与使用

1. 下载附件中的 **`Litematic-Viewer-1.3.0-beta-v2-win-x64.zip`**（适用 Windows 10/11 64 位，内置 Java 与 Electron 运行时，无需额外配置环境）。
2. 完整解压到可写目录（保留包内 `bin`、`runtime`、`assets`、`webapp` 等目录结构），双击 **`投影预览.exe`** 即可运行。
3. 可通过附件 **`SHA256SUMS.txt`** 校验压缩包与说明文件哈希完整性。
