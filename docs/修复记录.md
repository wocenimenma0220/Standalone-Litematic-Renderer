# 投影预览 1.2.0

本次为正式版发布，提交描述：**工作流更新**。

## 更新内容

- 二维画布在重新启动后恢复各视图上次暂存；正常关闭即时保存，运行中约每两秒暂存。恢复时验证格式和模拟队列，损坏存档给出提示。JSON 手动保存仍可用。
- 默认验证新增真实模型、光照、透明 PNG、旋转 GIF、缓存恢复和格式导入检查。持续集成新增二维界面、真实 Electron 三维加载与切换检查，保留可检查的画面和结果。
- 新增 Java 结构 `.nbt` 和 Sponge v2/v3 `.schem` 导入，包括方块状态、容器及实体 NBT。编辑和预览共用转换，导出为 `.litematic`，保留原始数据。
- 三维新增点燃 TNT、下落方块、掉落物静态展示。下落方块按材质分别处理透明与不透明面；分块统计也包括没有可绘制模型的实体，并在界面提示未显示数量。
- 拆出材料面板，格式转换集中到独立模块。界面、锁文件、启动器与包名使用统一版本来源，修正版本拼写。
- 支持从本地 Minecraft Java 客户端 JAR 准备资源；导入失败保留原资源。安装使用锁文件，打包提高压缩等级。
- 新增面向使用者的根目录 README，以五张当前功能截图介绍预览、选区、材料、编辑和二维搭建；随附可复现的功能演示投影。
- 正式版版本号统一为 `1.2.0`。发布工具按版本自动区分正式版与测试版，正式版标记为 Latest。

## 下载与使用

下载 `Litematic-Viewer-1.2.0-win-x64.zip`，完整解压后运行 `投影预览.exe`。Windows x64 便携包内含 Java 与 Electron，无需另装运行时。保留解压后的目录结构。

附件 `SHA256SUMS.txt` 提供安装包和更新说明的 SHA-256 校验值。

## 当前保留的功能边界

二维模拟仍是平面实验工具，未扩展为完整原版服务器。随机刻、区块加载、面外更新、生产配方、完整 AI 与主三维模拟联动尚未实现；入口和容器面板已明确提示。

目前新增的导入格式不包含旧数字 ID `.schematic`、SNBT 或基岩版结构。多套调色板 Java 结构使用第一套；不自动执行游戏的 DataFixer 迁移，较旧版本资源仍可能需要人工适配。新增格式限制为 1600 万格。

新增实体是保存时刻的静态外观；全部原版实体尚未覆盖。自有资源夹具用于自动验证渲染流程，完整游戏材质与大型投影的外观仍需要另行检查。Electron 运行时仍占分发体积的主要部分。
