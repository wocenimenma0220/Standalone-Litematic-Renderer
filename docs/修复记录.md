# 更新记录

# 投影预览 1.3.0-beta（1.3.0β 测试版）

本版本为 `1.3.0` 正式发布前的 **1.3.0β 预发布版本（Pre-release）**，主要汇集了近期界面深色风格统一、三维/流式渲染与导出性能优化、取消与缓存稳定性改进，以及测试工程目录整理等内容。

## 主要改动

### 界面风格与交互
- **GitHub Primer Dark 深色主题**：统一主窗口、三维投影编辑面板和二维搭建画布的深色配色、边框对比度与控件层级。
- **三维编辑面板响应优化**：编辑面板改为按需加载图集与音效，使用 CSS 雪碧定位图标和增量 DOM 复用面板按钮，并缓存编辑补丁图集避免重复解码，降低打开与切换分类时的卡顿。

### GPU 视图与流式加载
- **坐标检索与着色器复用**：在 `GpuView` 中为编辑掩码与搜索高亮坐标纹理改用空间开放定址哈希查找，并让编辑/选区辅助视图复用主视图已编译着色器；减少冗余 GL 状态切换。
- **遮挡剔除与 LOD 调度**：遮挡剔除触及单帧预算时仅当帧回退完整视锥，不再永久关闭；`LodStream` 改用八叉树范围查询筛选视距内区块，移除高频率相机比对时的字符串序列化，并在半透明排序回传时仅上传实际使用到的索引分片。

### Java 渲染引擎与后台导出
- **控制指令不阻塞与可取消渲染**：`JsonRpcServer` 分离耗时任务与控制指令处理，导出/渲染期间仍可及时响应 `cancel`、`cancelPreview`、`previewStatus`、`ping` 与退出；光栅化、`LightVolume` 和 GIF 编码循环定期检查中断信号并推送预览进度事件。
- **GIF 导出与图集拼接提速**：`GifWriter` 使用 64KB 字节批缓冲读写临时帧数据，并以固定数组哈希表替代 LZW 编码阶段的 `HashMap`；`Image.blitFrom` 与 `SpriteAtlas` 改用按行批量拷贝，图集较高时自动尝试宽幅布局压缩高度。
- **分块导出、光照与点选优化**：`StreamMeshExporter` 将分块压缩（`Deflater`）、CRC 校验和 LOD 简化并行下沉到工作线程；`SceneBuilder`、`LightVolume` 与 `SparseLightVolume` 复用临时数组、使用开放定址索引替换高频哈希查找、按曼哈顿距离由近及远计算空区天空光，并减少不必要的主动 GC；流式点选新增 64 格 LRU `ScenePicker` 缓存。
- **皮肤、缓存与后台导出稳定**：`SkinResolver` 复用下载线程池并添加 5 分钟短期负缓存以跳过重复失效请求；`CacheFingerprint` 在文件较多时并行计算目录 SHA-256 指纹；`SceneCache` 清理旧缓存文件时增加 Windows 占用重试；后台 PNG / GIF 导出支持 60 秒空闲回收的暖进程复用、跨分区移动文件自动回退复制替换，以及取消时的强制停止。

### 工程整理

- 统一应用、锁文件与启动器版本为 `1.3.0-beta`。

# 投影预览 1.2.0

提交摘要：**工作流更新**

## 改动内容

- **二维自动暂存与恢复**：二维画布运行中每两秒暂存一次，关闭画布或正常退出时即时写入；重启后分别恢复侧视与俯视画布（默认保持暂停），加载前校验快照和模拟队列完整性。
- **结构格式扩展**：新增导入 Java `.nbt` 和 Sponge v2/v3 `.schem`（含方块状态、容器及实体 NBT），编辑后统一导出为 `.litematic`。
- **三维实体扩展**：新增点燃的 TNT、下落方块与掉落物静态模型展示；分块加载支持统计未显示实体的数量提示。
- **界面拆分与版本统一**：拆出独立材料统计面板与格式解析模块，使用 `tools/version.cjs` 统一界面、锁文件、启动器和压缩包版本号，提高打包压缩等级。
- **本地资源准备**：支持通过 `-ClientJar` 从本地 Minecraft Java 客户端提取材质模型，导入校验失败时保留原有资源。
- **自动化检查增强**：持续集成补充真实 Electron 桌面端画面检查及浏览器二维界面回归。

## 已知边界回顾

- 二维画布保持单层平面实验定位（不含随机刻、区块加载、配方生产或完整生物 AI）；文件内若原导出缺失库存/实体数据，工具无法补全。
- 附加格式仅支持不超过 1600 万格的 `.nbt` / `.schem`，不包含旧数字 ID `.schematic`、SNBT 或基岩版结构。
