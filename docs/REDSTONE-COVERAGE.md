# 二维机制覆盖清单

核对日期：2026-10-19。实现依据本地 Minecraft Java 26.3 普通规则。当前方块目录1157项（含2种物品框），另有33种实体形态；“有模型、可放置”不代表全部游戏机制完成。只运算独立二维画布。

## 实体类

独立“实体类”栏新增33种形态，复用此前三维中已支持的原版模型：

- 7种矿车：普通、运输、动力、漏斗、TNT、命令方块、刷怪笼矿车。
- 11种木材的船/运输船，竹对应筏/运输筏，共22种。
- 雪傀儡、铁傀儡、成年猪灵、幼年猪灵，共4种。

已有物品框/荧光物品框也归入该栏，栏内共35项。生物和船没有寻路、目标、战斗等AI，保持放置位置；可以被活塞推动。矿车参与EU阶段运动。刷怪笼矿车不生成新生物，避免超出指定实体范围。掉落物、弹射物、点燃TNT及下落方块作为机制内部实体生成。

右键容器实体沿用当前背包UI；右键实体可改朝向，矿车可设初始速度，动力矿车可设燃料。实体位置、速度、库存、乘客、引线和EU队列可保存、撤销及恢复。实体接触压力板，木按钮持续检测箭；保留原来的手动压力板/探测轨输入以便独立测试。

## 原有机制继续保留

- WTU→TT→CT→BE→EU→TE→AT阶段、NC/PP嵌套、计划刻去重和优先级。EU现在实际处理上述实体；CT仍无随机刻。
- 红石块、附着拉杆、中继器、比较器、侦测器、红石灯、铜灯、红石粉、红石火把/烧毁恢复、按钮、压力板、音符盒。
- 比较器按容器满度/合成器占用与锁槽/讲台页码/唱片/雕纹书架最后槽/置物架位掩码/物品框/各种状态源读取。CUD保持水平定向通知，不扫描全图修正无更新状态。
- 原版更新入口保留比较器、发射器/投掷器的BUD/CUD状态，不用每刻重算全部电路。
- 背包鼠标拿取、拆分、拖动分配、快速转移、双击收集、快捷栏交换、合成器空槽锁定；物品组件及损伤在鼠标操作、传输、快照中保留，不同组件不叠加。
- 1658种原版物品的堆叠、耐久及堆肥数据已导出；容器材料栏补充为62种非方块物品图标，并保留原方块/实体材料。

熔炉/高炉/烟熏炉、合成器、酿造台按要求只提供库存及相应比较器检测，不烧炼/合成/酿造；末影箱27格个人共享，不提供比较器或漏斗接口。阳光探测器实际功能、随机刻、实验性红石及主三维联动按要求不引入。

## 其他仍未实现的主要机制

标靶命中强度、绊线/绊线钩实体连线、避雷针雷击、幽匿振动传播/筛选/冷却、钟/紫水晶振动、大型垂滴叶倾斜、完整落沙与原版流体、区块加载卸载等。嘎枝绑定、振动等未接入实体依赖仍通过面板输入。实体不包含AI，不扩充到其他生物。

## 验证与复现

- 原有87组时序/元件/库存/支撑/红石粉/器件检查，以及新增13组门类/实体和20组世界交互，共120组。全部加载完整二维模块再次运行通过；另有原有世界、活塞模型和像素方向检查。
- 5套实际界面检查：统一操作、实体类、器件、侧推双侦测器时钟、红石粉。覆盖矿车库存/运动、陷阱箱开箱信号、门上下半、微时序中途保存和恢复，并查看活塞收回截图。
- 运行库对照保留：375个模拟量状态、120个火把方向输出、92个轨道端点、384组库存满度、512次随机选槽、256组红石粉连接/输出/通知参考。
- 支撑/导电/接线以及碰撞/推动反应来自1286种方块、35723个状态。实体264张侧视/俯视贴图复用现有三维实体模型，不接入主三维模拟。
- `tools/generate-board-physics.ps1`离线重导碰撞、推动反应、木头标签和物品属性；`-WithEntitySprites`重导实体贴图；`tools/generate-board-items.py`重导库存图标。
- [矿车环线与容器检测示例](examples/矿车-环线与容器检测.json)：打开后点击开始运行，运输矿车沿动力环线循环，经过探测轨时由比较器读取库存并点灯；已验证160gt。

100000次事件预算不等于原版更新深度或maxChainedNeighborUpdates。完整flags副作用、全部HashMap边界、物品组件专属行为和原版漏洞尚未逐项复原；以上检查不代表完整ServerLevel逐事件差分已完成。本次以1.2.0test-v1预发布版本打包，另附[测试版说明](二维微时序测试版说明.md)。
