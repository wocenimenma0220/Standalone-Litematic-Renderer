# 二维 MC 时序

实现口径为本地 Java 版26.3默认规则。只接入独立二维搭建，不接入主三维投影视图。当前仍不是完整原版模拟器。

## 试用与操作

进入“二维搭建”，选择侧视或俯视即可。所有已接入机制同时启用，不再选择演示种类。新画布默认暂停在0gt，时序工具栏和微时序面板默认隐藏；点击“开始运行”才连续推进，点击“显示时序”查看计划刻、单步和事件记录。打开已保存画布同样暂停；旧静态画布会初始化已有信号源。放置/操作引起的即时NC/PP在当前AT执行，暂停期间不自动推进计划刻。点击“完成本刻”可完成中途更新；隐藏时序面板时也会完成当前更新链，避免留在中间阶段而无法放置。

左键放置，右键直接操作拉杆、按钮、中继器、比较器、音符盒和红石粉；右键压力板打开模拟踩压，右键容器打开背包面板。Shift＋右键拖动方块并保留库存。侦测器无需支撑，侧视默认朝东以保证检测/输出位于平面内，也可选其他六方向。音符盒每次右键音高加一（0–24循环）、发送更新并登记BE；面向它的侦测器可检测该变化。压力板检测已接入实体，并保留手动接触数量；音符盒暂不扩展特殊音色，符合当前范围。

红石粉默认由十字状态放置，不显示手动电量/方向选项。连接按原版自动形成直线、拐角和爬升；十字粉/点粉可右键切换，已有连接时保留原版限制，不强行断开成点粉。传播使用DefaultRedstoneWireEvaluator：非线信号先屏蔽全部红石粉输出，邻线电量取最大后减1；普通红石更新按NC/PP深度优先执行，7个通知位置保留Java HashSet/BlockPos顺序。支持俯视平面引线及侧视平面可达的高低线、导体阻挡和向下强充能；不使用实验性传播。

红石块持续向周围输出15级弱信号，可点亮相邻灯、锁定漏斗、驱动活塞；它不会像拉杆那样强充能旁边的实体方块。拉杆须有与附着面和方向匹配的支撑：墙面facing指向墙外，地面附着下方，顶面附着上方。拉杆仅向附着方块强充能，弱信号仍向周围输出，遵循LeverBlock，而不是把所有输出都改成单向。

支撑与导电分开判断：本地原版运行库导出1286种方块、35723个状态的支撑面。拉杆/按钮要求附着方块朝向元件的一面为FULL；中继器/比较器要求下方RIGID上表面；压力板接受RIGID或CENTER。玻璃和红石块可支撑，台阶/楼梯按状态和方向判断，树叶不提供支撑。放置、拖动与支撑变化后的脱落均使用同一判定；预览用红框标识不可放置。俯视地面保留隐式支撑。可用tools/generate-board-support.ps1离线重新导出数据。其他尚未接入机制的附着类方块仍需分别补生存规则。

容器采用与原背包一致的深色卡片、图标槽位、数量角标及36格个人背包。右侧为可搜索的方块工具栏，可以直接拖入槽位；左键取一组、右键取一个。打开面板暂停，关闭后恢复原运行状态；库存修改立即触发比较器更新并随画布保存。

| 鼠标/按键 | 操作 |
| --- | --- |
| 左键槽位 | 拿起整组、放下、合并或交换；超过上限的部分留在手中。 |
| 右键槽位 | 空手取一半（向上取整），手持时放一个。 |
| Shift＋点击 | 在容器和背包之间快速转移，先合并再找空格。 |
| 左键拖过多个槽位 | 均分手持物品，余数留在手中。 |
| 右键拖过多个槽位 | 每格放一个。 |
| 双击 | 收集容器及背包里的同类物品，直到堆叠上限。 |
| 鼠标悬停＋1–9 | 与对应快捷栏交换。 |
| 中键槽位 | 从已有物品复制一组（工具栏为无限材料的搭建环境）。 |
| Ctrl＋Z / Ctrl＋Shift＋Z / Ctrl＋S | 撤销、重做、保存，容器面板内同样可用。 |

关闭时手持物品优先放回背包；背包满时尝试容器，仍无空间则保留面板并提示放下。只有明确点击“丢弃手持物品”会移除手持物品。尚未实现Q键丢出实体、容器外点击生成掉落物、物品组件交互和全部原版特殊菜单规则。

支持逐游戏刻、阶段、事件推进。阶段中途禁止编辑，玩家操作完成当前AT更新链。自动运行目标每刻50ms，卡顿降低速度但不跳过刻。事件记录含编号、父编号、gt、阶段、坐标、状态变化；点击定位并在底部显示详情。保留最近2000条，显示筛选后的最近100条，可导出记录与完整执行快照。

## 二维约定

| 视图 | 左/右 | 屏幕上/下 | 垂直屏幕 |
| --- | --- | --- | --- |
| 侧视 | 西/东 | 上/下 | 北向内、南向外 |
| 俯视 | 西/东 | 北/南 | 上向外、下向内 |

画布左上角和方向按钮均标注中文。内部沿用六方向坐标便于对照源码，但只允许当前二维平面存在、移动和传输方块。没有隐藏编辑层或主三维联动。俯视元件采用隐式地面支撑，不创建隐藏石头；面外漏斗不传输，面外活塞记录提示而不推动。第一轮隐藏支撑在恢复时排除。

### 优先级

值越小越优先；同刻同优先级按subTickOrder。相同位置和类型已排队时仍去重，不为新优先级改写已有计划刻。

| 元件 | 延迟 | 默认优先级 | 特殊情况 |
| --- | --- | --- | --- |
| 中继器 | 挡位×2gt | -1 | 已亮准备灭-2；输出前方二极管符合shouldPrioritize条件时-3；短脉冲后续熄灭-2。 |
| 比较器 | 2gt | 0 | 同一shouldPrioritize条件下-1。 |
| 侦测器 | 2gt | 0 | 无。 |
| 红石灯 | 熄灭4gt | 0 | 亮起瞬时。 |
| 按钮/压力板 | 上述释放/复查间隔 | 0 | 无。 |

二极管新放置时有输入的1gt计划刻沿用放置入口，不误用邻居更新延迟。

### 容器

支持漏斗5格、箱子/陷阱箱/铜箱/木桶/潜影盒27格、匹配双箱54格、投掷器/发射器/合成器9格、熔炉/高炉/烟熏炉3格、酿造台5格。满度按物品自身堆叠上限计算；合成器读取占用格数。熔炉和酿造台实现基础侧面槽位限制，熔炉下方优先输出槽再燃料槽。

物品保留ID、数量、堆叠上限、损伤及组件，堆叠上限来自1658种原版物品组件（含潜影盒、告示牌、旗帜）。合成器显示3×3槽位：空手左键点击空槽锁定，再点解锁；手持物品点击锁格会先解锁再放入，有物品的格子按正常拿取操作，不能直接锁定。锁格阻止漏斗/快速转移/拖动分配放入，计入比较器输出，并随保存及撤销恢复。面板不要求手输ID和数量；旧存档中的其他物品仍保留。尚未覆盖全部物品组件的专属行为及燃料/配方注册表。合成器尚未实际合成；熔炉不烹饪，酿造台不酿造，投掷器/发射器已接入4gt计划刻、QC和发射；陷阱箱根据当前面板打开/关闭同步查看人数及红石信号。末影箱采用个人共享27格库存，不提供模拟量或漏斗接口。箱子上方导体遮挡影响比较器读数；完整菜单和侧面规则仍待扩展。

## 源码依据与边界

本地源码在项目根目录的 ../../26.3-client-src/net/minecraft/。已对照ServerLevel、ScheduledTick、LevelTicks、NeighborUpdater、CollectingNeighborUpdater、Level、BlockBehaviour、DiodeBlock、RepeaterBlock、ComparatorBlock、PistonBaseBlock、PistonStructureResolver、PistonMovingBlockEntity、PistonHeadBlock、HopperBlock、HopperBlockEntity、ButtonBlock及压力板系列源码。本轮补充PoweredBlock、LeverBlock、FaceAttachedHorizontalDirectionalBlock、NoteBlock、Items，以及AbstractContainerMenu的PICKUP/QUICK_MOVE/PICKUP_ALL/SWAP/QUICK_CRAFT规则。

红石粉另外对照RedstoneWireBlock、DefaultRedstoneWireEvaluator、RedstoneWireEvaluator、SignalGetter；合成器锁槽对照CrafterScreen、CrafterMenu、CrafterSlot及CrafterBlockEntity。执行 `tools/generate-board-support.ps1 -VerifyWire` 可离线生成256组原版运行库参考，直接调用原版连接方法、六向弱/直接信号和HashSet通知集合，随后与二维实现比较。该对照不包含整个ServerLevel中的完整传播轨迹。

保留中继器短脉冲、侦测器仅查后续计划集合、铜灯同刻多次翻转、QC无更新BUD和黏性短脉冲丢块等行为，不改成理想电路。

红石火把、四类铁轨、门类、陷阱箱人数信号、树电/脚电和指定实体均已接入。EU处理矿车、掉落物及弹射物等实体，活塞支持实体推挤，推动反应使用原版状态导出数据。随机刻与实验性红石按需求不引入；原版流体、区块卸载/重载和全部实体环境行为仍未完成。支撑、导电及红石粉连接属性均从原版运行库按方块状态导出，不再用导体白名单；实际输出行为仍限于已接入的元件。逐类缺口见[方块覆盖清单](REDSTONE-COVERAGE.md)。

100000次事件预算是工具保护，不等于原版更新深度或maxChainedNeighborUpdates。完整flags副作用、HashMap相关边界行为和所有原版漏洞尚未逐项复原。源码对照和本地回归不等于已完成原版运行时逐事件差分验证。

### 侧推双侦测器时钟示例

打开[侧视侧推示例](examples/observer-side-push.json)，点击“开始运行”：活塞向上把左侧侦测器推到右侧侦测器旁，左侧检测面朝东、右侧检测面朝西。3gt右侧亮、5gt左侧亮，随后每2gt交替，单只侦测器周期4gt。`tools/verify/board-observer-clock-ui.cjs`从空画布用实际鼠标搭建，并分别检查单步、示例载入和自动运行中的持续互相触发。

侦测器的facing代表脸的检测方向，纹理箭头则朝向相反的输出面。二维状态栏标为“检测方向”，同时列出检测面和输出面。生成贴图时按原版FaceInfo/CuboidFace的UV角顺序排列竖直面，避免横向镜像箭头；`board-observer-sprite-regression.py`直接核对侧视/俯视的实际箭头像素方向，不能只靠保存状态或逻辑模型检查。

红石火把2gt反相，60gt内8次熄灭烧毁、160gt计划恢复；墙上火把facing朝外，附着在相反方向。普通铁轨自动连形/转弯/坡道，三岔路口只在相应信号源NC下重新选向；动力轨和激活轨只沿同类同轴传电，搜索深度8。探测轨检测真实矿车和容器信号，20gt复查释放；原来的右键模拟输入继续保留。矿车采用普通规则运动，详见下方实体补充。

## 二维实体与门类补充

底部新增“实体类”，包括此前三维支持的7种矿车、22种船/运输船（含竹筏）、雪傀儡/铁傀儡/成年及幼年猪灵，另列已有2种物品框。选择后左键放置；右键打开实体设置或容器。生物与船没有AI，保持静止；矿车在EU阶段沿普通轨道规则运动，可设朝向/初始速度及动力矿车燃料刻数。

容器矿车和运输船沿用现有背包操作，可参与漏斗传输。探测轨读取实际矿车库存，命令矿车优先提供成功次数。激活轨使普通矿车下客、禁用漏斗矿车、点燃TNT矿车；命令矿车4gt冷却执行有限画布命令。刷怪笼矿车只提供模型，不生成额外生物。

侧视门从下半部放置，会占据上下两格；门类右键或红石控制开关，铁门/铁活板门只能由红石控制。陷阱箱开箱时输出1，关闭输出0。树叶和脚手架通过1gt计划刻传播距离，无随机刻。压力板检测真实实体，木按钮的箭压在计划刻复查时保持连续供电。

活塞收回时底座固定，移动层只移动活塞头；取消整个底座随头移动/透明绘制，修复高频推动时的底座闪烁。移动碰撞形状与原版推动反应一起用于实体推挤。

库存保留组件、耐久和原版堆叠上限；发射器补充矿车/船、剪南瓜、耐久、部分作物骨粉和蜂蜜交互。堆肥桶可用面板投料或漏斗投入，7层后20gt成熟为8层，漏斗可取骨粉。蜂箱可设置巢内数量/花蜜/驻留刻数，出口堵塞时保留居民数据；不运行蜜蜂AI。
