# 二维 TNT 与流体实现笔记

本文记录二维搭建画布中 TNT、通用爆炸与流体的设计约定及文件分布。三维投影查看器本身不运行实体模拟。

## 上手测试

- 放置 TNT 方块后，手持打火石右键或用相邻红石即可点燃；也可从“实体类”里直接摆“点燃的 TNT”，右键调它的剩余引信、威力和初速度。
- TNT 默认引信 80gt，最后 10gt 膨胀闪烁并显示倒计时；画布处于暂停、连续运行或单步模式时共用同一份模拟世界状态。
- 水方块支持选择不同液位，按 5gt 周期执行流体计划刻，源头拆掉后会逐渐退水，流动水会推着 TNT 和掉落物走。
- 示例存档：[TNT 水流运输与爆炸冲量](examples/TNT-水流运输与爆炸冲量.json)——运行后第一颗 TNT 在 80gt 引爆，周围水体护住方块，同时把另一颗 TNT 炸飞。
- 存档恢复包含所有流体、实体、Legacy 随机源状态以及执行到一半的爆炸射线/破坏队列；触发事件预算暂停后点继续还能接着算完。

## 实现要点

- **TNT 与矿车**：对齐 Minecraft Java 26.3 默认参数（0.98×0.98 尺寸、底面中心生成、随机水平微速 +0.2 竖直初速、空气阻力 0.98F、地面摩擦 0.7）；红石供电、打火石、发射器、火矢和火苗共用点燃入口；连锁点燃使用 10–29gt 随机短引信；爆心设在 `y + height * 0.0625`。TNT 矿车单独接入激活轨、高速撞击、跌落与着火箭引爆及护轨规则。
- **爆炸射线与精度**：按 1352 条射线、Java `float` 衰减、Legacy 48 位随机源与 Java HashMap 桶序洗牌计算。每格抗性取方块与流体的较大值；先求受影响集合与实体暴露度/冲量，再执行方块破坏、连锁点燃与更新；渲染和音效不消耗物理随机数。
- **时间切片**：射线与破坏逻辑按预算分片让出主线程，不把巨型爆炸堵死在同一帧同步循环里。
- **流体**：流体计划刻在同 gt 的方块计划刻之后调度。实现了水源高度（8/9 与上连满格 1）、坡度寻路、双水源转换、含水容器透水面判定、水/岩浆凝固与玄武岩生成，以及与 TNT 独立的掉落物水中浮力。

## 平面约定

- **侧视（z=0）**：实体法向（Z 轴）速度锁零，流体不跨出平面，面外射线按空气穿透计算（单层切片模型）。
- **俯视（y=0）**：实体保有 Y 轴高度与重力，y < 0 存在隐式碰撞/遮挡地面但不会被炸毁，不产生额外掉落物。
- 继续沿用 192 格编辑范围与 256 格实体清理阈值，暂停或关闭画布后引信静止，不使用真实墙钟倒计时。
- 默认单颗 TNT 干/湿场景的射线集合、破坏序与 RNG 消费已由独立 Java 运行时夹具校验；超出 2D 边界机制（如随机刻、战利品表、地狱熔岩流速、完整生物战斗、极高自定义威力下的桶退化差异）暂不在支持内。

## 相关模块与验证

| 文件 | 作用 |
| --- | --- |
| `webapp/renderer/board-fluid-data.js`、`board-fluids.js` | 方块材质标签、流体状态、计划刻、碰撞面与实体推力 |
| `webapp/renderer/board-explosions.js` | 1352 射线、抗性、暴露度、击退冲量、破坏队列与切片快照 |
| `webapp/renderer/board-tnt.js` | TNT 与矿车实体逻辑、点燃入口和属性编辑器 |
| `webapp/renderer/board-entity-sounds.js`、`board.js` | 音效资源映射与画布显示交互 |
| `tools/verify/board/board-tnt-regression.cjs` | TNT、流体扩散、爆炸顺序、RNG 及读档回归单测 |
| `tools/verify/board/board-tnt-ui.cjs` | Playwright 端到端 UI 操作与中途存档验证 |
| `tools/verify/board/TntFluidReference.java`、`tools/verify/fixtures/tnt-fluid-26.3.json` | Java 原版 26.3 运行时射线与洗牌校验夹具 |

跑 `./verify.ps1` 与 `./verify.ps1 -Ui` 即可覆盖上述测试。流体标签数据与音效分别通过 `tools/generate-board-fluids.ps1` 和 `tools/generate-board-entity-sounds.py` 从本地客户端缓存导出，不依赖联网。
