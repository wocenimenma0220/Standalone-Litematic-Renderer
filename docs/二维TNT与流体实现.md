# 二维 TNT 与流体

版本沿用 `1.2.0tetst-v2`。本次只修改二维搭建与微时序，不让三维投影运行实体。

## 操作

- 放置 TNT 方块，右键使用画布中的打火石操作点燃；相邻红石供电也可点燃。
- “实体类”新增“点燃的 TNT”，可直接放置。右键该实体可以修改剩余引信、爆炸强度和速度。
- 默认引信 80gt。默认暂停；开始运行、逐刻、逐阶段、逐事件均使用同一模拟状态。最后 10gt 膨胀、白色闪烁并显示剩余引信。
- 水方块使用所选液位，每 5gt 执行水流计划刻；源水移除后流水会退去。水流可以运输 TNT 和掉落物。
- 试验示例：[TNT 水流运输与爆炸冲量](examples/TNT-水流运输与爆炸冲量.json)。打开后运行，第一颗 TNT 于 80gt 爆炸，水保护周围方块，但另一颗 TNT 仍会受到冲量。
- 保存和打开保留流体、实体、随机源与尚未完成的爆炸任务。事件预算暂停时，点击继续运行可保留游标续算。

## 已实现的核心链路

TNT 类型默认值、原版随机初速度、重力与空气阻力、落地参数、含水查询和水流冲量；红石、手持打火石、发射器 TNT/打火石、燃烧箭和火焰接触点燃；80gt 引信、10–29gt 连锁引信和爆心高度偏移。

爆炸按 1352 条射线计算，采用 Java float 运算、世界 Legacy 随机源及普通 Java HashMap 桶顺序和洗牌。方块与流体共同决定抗性，先计算实体暴露度、基础伤害和冲量，再执行方块破坏、更新与连锁点燃。已点燃 TNT 免普通伤害，但接受冲量。

TNT 矿车接入激活轨、撞击、坠落、燃烧箭、爆炸伤害引燃、速度增幅，以及点燃时保护铁轨和轨下支撑的例外。原有矿车库存与探测轨保持原来的接口。

流体计划刻在 TT 中的方块计划刻之后执行。普通水包含液位、下落、水源转换、坡度寻路、碰撞面通水、含水容器、冲刷及退流。基础熔岩采用普通维度的间隔与传播，支持水岩浆凝固和玄武岩条件。掉落物浮力、气泡柱接触、特殊材质速度/摩擦/弹性参数独立于 TNT 参数。

爆炸射线分批执行，每帧使用有时间预算的模拟片段；不把整次爆炸塞进一个同步函数。显示和音效不消耗物理随机数。保存可恢复射线、实体影响和方块破坏阶段，不重复抽随机数。

## 二维约定和边界

- 侧视只编辑 z=0，实体固定法向速度为零；流体不能向面外传播。爆炸射线面外查询为空气，代表单层截面，不代表无限厚墙。
- 俯视只编辑 y=0，实体仍有真实高度与重力。y<0 的隐式地面参与碰撞、流体阻挡和遮挡，但不可被炸掉，也不产生隐藏方块掉落。
- 仍有原来的 192 格编辑边界与 256 格实体清理边界。结果按模拟 gt 推进，不按独立墙钟计时；关闭或暂停画布时 TNT 不在后台继续倒计时。
- 没有接入生物 AI、护甲、完整伤害冷却和队伍规则。现有静态生物接受基础爆炸伤害与冲量，不等于完整原版生物。
- 火焰接触点燃属于有限画布兼容规则；没有实现完整火焰传播、雨、湿度、随机刻或跨维度传送门。熔岩没有地狱维度预设的全部差异。
- 掉落沿用项目已有的物品映射与容器内容物处理，没有接入完整原版战利品表；不是所有方块被炸后都已还原原版掉落。
- 默认强度场景的射线集合、洗牌顺序和随机数消费已与 Java 参考夹具一致。Java HashMap 树化桶、所有自定义高强度场景和原版全服务器环境不在当前一致性证明内。

这些边界不应通过“全部原版行为已实现”的表述隐藏。当前交付覆盖本轮 TNT、水流运输、爆炸冲量、连锁和微时序保存的核心流程。

## 实现与验证

| 文件 | 职责 |
| --- | --- |
| `board-fluid-data.js`、`board-fluids.js` | 原版标签与材质参数，流体状态、计划刻、碰撞面和实体受力 |
| `board-explosions.js` | 射线、抗性、暴露度、基础伤害/冲量、破坏队列与快照 |
| `board-tnt.js` | 类型默认值、点燃、TNT 与矿车运行、接触和参数设置 |
| `board-entity-sounds.js`、`board.js` | 真实资源缓存提取的音效、画布显示与交互 |
| `tools/verify/board-tnt-regression.cjs` | 29 组 TNT、流体、爆炸、随机性和保存回归 |
| `tools/verify/board-tnt-ui.cjs` | 点燃、参数、撤销重做、引爆、流体、爆炸中途保存的真实界面检查 |
| `tools/verify/TntFluidReference.java`、`fixtures/tnt-fluid-26.3.json` | 独立 Java 运行时对照，包含干/含水场景的射线集合数量、破坏顺序校验和随机源终态 |

运行 `./verify.ps1` 包含新增逻辑回归，`-Ui` 包含新增界面回归。

`tools/generate-board-fluids.ps1` 从同版本 Java 运行时和标签重新导出数据，使用现有方块物理导出工具的类路径文件；也可显式指定 `Classpath`、`ReferenceRoot`、`JdkHome`。`tools/generate-board-entity-sounds.py` 从本机 Fabric Loom 资源缓存提取音效，缓存根目录与索引均可显式指定，工具不会联网下载。
