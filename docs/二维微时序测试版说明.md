# 二维搭建与微时序范围

当前版本：`1.2.0tetst-v2`。实现依据项目本地的 Minecraft Java 26.3 参考源码，只计算当前二维平面。目录中的方块可选、可显示，不代表全部原版行为已经实现。TNT 和流体的操作、验证及边界见[二维 TNT 与流体](二维TNT与流体实现.md)。

## 使用

打开“二维搭建”，选择侧视或俯视。模块首次使用时加载；画布默认暂停，点击“开始运行”推进，也可显示时序后逐刻、逐阶段或逐事件检查。

左键放置，右键操作元件或打开容器，Shift＋右键拖动方块，中键平移，滚轮缩放。撤销和重做支持界面按钮及 Ctrl＋Z / Ctrl＋Shift＋Z。保存导出 JSON，打开可恢复方块、容器、实体和执行队列；关闭后本次运行中可重新进入原画布。

## 边界

- 面外不放置或移动方块。俯视平面元件使用隐式地面支撑，朝平面外的漏斗不传输。
- 生物和船没有 AI。熔炉、合成器和酿造台保留库存，不执行实际生产。
- 未完整接入所有维度的流体差异、完整燃烧、落沙触发、全部特殊发射行为、药水效果、护甲与伤害冷却、完整战利品和环境机制。已有基础爆炸伤害与冲量，不代表完整原版生物战斗。
- 随机刻、实验性红石、区块加载卸载和主三维联动不在当前范围。
- 事件预算用于限制执行量，不等于原版更新深度。回归通过不代表完整原版世界的逐事件一致性。

微时序保留最近 2000 条记录，界面显示筛选后的最近 100 条。三维“更改投影”只修改保存状态，不触发这套二维模拟。

示例 JSON 位于 [examples](examples/)，包括比较器与雕纹书架、投掷器准连接和矿车环线。开发检查入口见 [开发与验证](DEVELOPMENT.md)。
