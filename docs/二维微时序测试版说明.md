# 二维搭建与微时序功能范围

当前版本：**1.3.0-beta**（1.3.0β 测试版）。物理与红石规则对齐 Minecraft Java 26.3 本地参考源码，只在当前选定的二维平面内演算。

## 基本操作

在主界面打开“二维搭建”，选择“侧视”或“俯视”：

- 画布默认暂停，点击“开始运行”连续推进；展开“显示时序”后可按游戏刻（gt）、微时序阶段或单个事件逐步单步调试。
- 左键放置方块，右键交互元件或打开容器，`Shift` + 右键拖动移动方块，中键拖动画布，滚轮缩放；支持 `Ctrl + Z` / `Ctrl + Shift + Z` 撤销重做。
- 可手动导出/加载 JSON 存档；同时侧视与俯视会各自定期自动暂存并在重开画布时恢复（恢复后默认保持暂停）。

## 已实现范围

| 类别 | 说明 |
| --- | --- |
| 红石元件 | 侦测器、中继器、比较器、红石灯、铜灯、红石火把、红石粉、铁轨及常见充能规则 |
| 计划刻与微时序 | 支持计划刻优先级/顺序、阶段推进、NC/PP 更新、方块事件，可在执行中途保存恢复 |
| 活塞 | 普通/黏性活塞、平面内准连接与 BUD、黏性推拉分支、短脉冲丢块、移动块碰撞与推挤实体 |
| 容器与漏斗 | 箱子、漏斗、发射器、投掷器库存拿取/拆分/转移；漏斗红石锁定、先出后入、冷却与掉落物/矿车交互 |
| 交互方块 | 门、活板门、按钮、压力板、陷阱箱、音符盒、讲台、雕纹书架、合成器锁槽 |

## 使用边界

- 侧视与俯视仅各自维护当前单层（俯视自带隐式地面承托，面向平面外的漏斗不会向平面外传物）。
- 生物和船只保留占位物理与基础受击/冲量，无 AI、护甲或完整伤害冷却；熔炉、合成器和酿造台仅保留库存不实际合成/烧炼。
- 不含随机刻、实验性红石、区块加载与主三维投影联动。
- 微时序面板最多记录最近 2000 条日志（列表展示筛选后的最近 100 条），并带有单步事件上限保护，防止死循环卡死界面。

更多测试存档见 [docs/examples](examples/)，开发测试入口见[开发与验证](DEVELOPMENT.md)。
