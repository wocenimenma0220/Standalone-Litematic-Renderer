# 1.2.0test-v1：二维构建下的微时序测试

更新日期：2026-10-19。适用范围为独立「二维搭建」的侧视和俯视。规则依据本地 Minecraft Java 26.3 普通红石源码；这是机制测试版，尚不能视为完整的原版世界模拟器。

## 一、目前已经实现

### 时序、操作与保存

- 所有已接入机制同时启用，新画布默认暂停在0gt，并隐藏时序面板。
- 支持连续运行、推进1gt、下一阶段、下一事件和完成本刻。微时序包含WTU、TT、CT、BE、EU、TE、AT阶段、邻居更新NC、形状更新PP、计划刻和方块事件。
- 保留计划刻去重、优先级、更新嵌套和因果链，能够查看、筛选、定位及导出记录。
- 明确标注东、西、南、北、上、下；只运算当前二维平面，俯视元件使用隐式地面支撑。
- 支持画布保存、载入、撤销和重做；实体、库存、冷却、活塞移动进度，以及微时序中途的待执行队列均可保存恢复。

### 红石元件与更新机制

| 方块或机制 | 已实现内容 |
| --- | --- |
| 红石块、拉杆 | 常亮信号，拉杆附着面检查、方向对应的强充能和脱落检查 |
| 中继器、比较器 | 延迟、模式、短脉冲、侧向锁定、计划刻优先级；比较器定向CUD和输出缓存 |
| 侦测器 | 检测面PP、2gt脉冲、检测面与输出面区分，侧推后脸对脸形成高频 |
| 红石灯、铜灯 | 延迟熄灭、上升沿翻转等状态与更新 |
| 红石粉 | 普通传播、衰减、退电、自动接线、高低线、十字与点切换 |
| 红石火把 | 支撑、定向输出、反相、烧毁和计划恢复 |
| 按钮、压力板、音符盒 | 手动按压/踩压、实体接触、木按钮箭压复查；音符盒右键调音和BE演奏事件 |
| 门、活板门、栅栏门 | 红石与手动开关，上下半门同步及支撑移除；铁门、铁活板门仅红石开启 |

比较器已读取普通/双箱/铜箱、木桶、漏斗、潜影盒、熔炉类、酿造台、发射器/投掷器、饰纹陶罐、合成器、雕纹书架、置物架、讲台、唱片机及物品框等对应数据，以及炼药锅、堆肥桶、蜂箱、蛋糕、重生锚等状态信号源。模拟量可读取不代表该方块的全部游戏过程已完成。

### 活塞、漏斗和容器

- 活塞/黏性活塞支持BE/TE、平面可达的准连接、BUD、短脉冲丢块、12块限制、黏液/蜂蜜分支及互不黏。
- 推动反应、不可破坏属性、方块实体属性及碰撞形状由原版方块状态导出；加入实体推挤、轴位移限制、黏液推速和蜂蜜携带。
- 修复高频收回时底座跟随平移、透明绘制而闪烁：底座保持固定，只移动活塞头。
- 漏斗支持先出后入、8/7gt冷却、红石锁定、掉落物吸入、与容器矿车/运输船传输，以及库存变化的比较器更新。
- 容器沿用背包UI，支持拿取、拆分、拖动分配、快速转移、双击收集、快捷栏交换。合成器空槽左键锁定/解锁。
- 物品组件和损伤在鼠标操作、传输、实体库存与保存中保留；组件不同不叠加。1658种原版物品的堆叠、耐久和堆肥属性已导出。
- 末影箱使用个人共享27格库存，不提供比较器信号或漏斗接口。

### 实体类、矿车和铁轨

新增「实体类」，沿用此前三维已支持的模型：7种矿车、11种木材的船/运输船（竹对应筏/运输筏，共22种）、雪傀儡、铁傀儡、成年猪灵和幼年猪灵，共33种新增形态。加上原有两种物品框，实体类栏共35项。

生物和船保持静止、没有AI，可以被活塞推动。矿车在EU阶段运行普通OldMinecartBehavior规则，支持直线、弯道、坡道、限速、阻尼、制动、动力轨启动及基础碰撞/乘坐。

四类铁轨均接入：普通轨道连接与转弯、动力轨传电与加速、激活轨下客/停用漏斗矿车/点燃TNT矿车/触发命令矿车，探测轨检测真实矿车并提供库存或命令成功次数。保留手动探测轨输入，便于独立搭建测试。

右键容器实体打开背包；实体设置中可调整朝向、矿车初始速度、动力矿车燃料。刷怪笼矿车只展示，不生成额外生物。

### 发射器、投掷器和信号源交互

- 发射器/投掷器具有4gt计划刻、准连接、TRIGGERED边沿和原版随机非空槽选择；保留更新入口产生的BUD/CUD状态。
- 投掷器优先向目标容器插入物品。发射器已产生真实物品、弹射物和点燃TNT，并支持矿车/船放置、收倒桶、打火石、剪南瓜/蜂巢、部分作物骨粉、蜂蜜瓶/水瓶、蜜脾上蜡及重生锚充能。
- 工具计入耐久；弹射参数来自原版物品配置，区分基础重力/阻力、火焰弹加速及烟花直射/寿命。TNT具有引线、连锁引线和按抗性射线破坏。
- 堆肥桶可以投料或由漏斗投入，7层后20gt成熟为8层，漏斗可取骨粉；炼药锅、蛋糕和重生锚接入相应基础交互。
- 蜂箱处理手动配置的巢内居民、花蜜和驻留计时，出口堵塞时保留居民数据。
- 命令方块具有脉冲/循环/连锁触发及条件、成功次数更新；目前只解释画布内的setblock、fill、summon，summon限支持实体和当前平面。

## 二、还没实现，或没有完整实现

| 范围 | 目前缺口 |
| --- | --- |
| 完整原版时序一致性 | 尚未完成完整ServerLevel逐事件差分；全部flags副作用、HashMap边界、更新深度和所有原版漏洞未逐项复原。100000次事件预算是工具保护 |
| 活塞特殊边界 | 特殊上下文碰撞、卡进底座后的全部纠偏、区块和世界边界等仍待核验 |
| 矿车和实体环境 | 完整损伤、脱轨事故、传送门、区块行为及全部实体相互作用；矿车目前只有基础乘坐/碰撞处理 |
| 发射器全部特殊行为 | 装备、其他生物生成、全部骨粉植物/树木生成等未全覆盖 |
| 弹射物与爆炸 | 完整命中伤害、药水/风弹/烟花效果、爆炸实体伤害及原版完整战利品规则尚未完成；碰撞使用平面AABB |
| 物品与容器规则 | 保存了组件，不代表全部组件的游戏行为已实现；全部特殊菜单、燃料/配方规则、箱子开盖动画等尚未完成 |
| 特殊信号源过程 | 完整命令系统、蜜蜂出巢采集/返巢、天气影响和全部植物生成未完成；幽匿振动、嘎枝绑定等仍依赖面板数据 |
| 其他红石方块 | 标靶命中强度、绊线/绊线钩实体连线、避雷针雷击、幽匿振动传播/筛选/冷却、钟/紫水晶振动、大型垂滴叶倾斜等尚未接入 |
| 世界模拟 | 原版流体、完整重力方块、天气、区块加载/卸载等尚未接入 |

这些是当前缺口，不应因为工具栏已有模型或允许手动调整状态，就视为已经完成。

## 三、按当前约定不考虑做

以下属于本阶段明确排除的范围，与上表的实现缺口分开记录；暂不作为本测试版的待办：

- 不将这套时序接入主三维投影视图，只服务独立二维搭建。
- 不引入随机刻和实验性红石/实验性新矿车逻辑。
- 不给生物和船加入寻路、目标选择、战斗或采集等AI；不自行扩充到指定名单以外的生物。
- 熔炉、高炉、烟熏炉不执行烧炼；合成器不执行合成；酿造台不执行酿造。保留可放内容物的UI和相关比较器检测。
- 阳光探测器暂不执行随日照变化的实际功能。
- 音符盒暂不扩展特殊音色与完整乐器环境判定。

“不考虑”以目前已经约定的需求为准，不表示以后不能重新调整范围。

## 四、试用及验证

完整解压Windows便携包，双击根目录的「投影预览.exe」，进入「二维搭建」，选择侧视或俯视，再点击「开始运行」或「显示时序」。此说明随压缩包提供，也可在GitHub单独下载。

已通过120组机制回归及5套实际界面检查，并保留原版运行库的静态模拟量、方向输出、铁轨端点、库存满度、随机选槽和红石粉参考对照。矿车环线示例已运行160gt验证轨道运动及比较器点灯。这些验证不能替代完整原版世界一致性验证。
