    预览渲染

    GPU 支持实时旋转、缩放和漫游。

    根据方块数量与空间范围自动选择，小投影完整加载，大投影先看总览。

    开启后先显示简化总览，再按视角逐块补充完整细节；已载入部分会保留。

    大投影渲染开启时，近处保留完整细节；关闭 LOD 后区块始终使用完整精度。PNG / GIF 始终保持完整精度。

    随视角按需加载，缓存中的细节可重复使用。

    控制已生成细节的提前加载范围。完整区块按视角优先生成，其余继续后台补齐；预览可同时操作。缓存不足会暂停，可提高上限后继续。

    32–16384 MB，初始值按机器内存选择，可手动调整。投影、光照和贴图另占内存。

    1–128 区块，默认 6；每区块宽 16 格。仅限制漫游中的水平范围，轨道总览与导出显示完整投影。

    磁盘场景缓存

    再次打开大投影时复用完整画面。0 为关闭；256–131072 MB。使用期间保留当前场景。

    默认开启；关闭后可在下次启动时复用场景缓存。

    光照

    开启光照渲染后计算明暗；平滑光照让顶点之间自然过渡。关闭平滑光照使用明亮效果，关闭光照渲染直接显示材质。

    视角

    在预览区拖动即可旋转，滚轮缩放；按 V 进入漫游。

    漫游中：W/A/S/D 移动，空格 上升，Shift / C 下降，Ctrl 加速；移动鼠标转视角，左键查看准星所指方块或实体，Esc 释放鼠标，V 退出。

    查看内部

    选择渲染控制显示；工具只负责选点。关闭工具仍保留选区显示。

    开启后左键选角点 1，右键选角点 2；Alt＋滚轮沿观察方向移动当前角点，逐层模式下切换高度。漫游移动与转向照常，选择优先于查看方块。

    输出

    网格仅用于预览，导出时自动透明。

    PNG 支持 512～81920 及「无损」（按当前材质包贴图分辨率自动计算最高清晰尺寸）；GIF 围绕模型中心轴匀速旋转一周，缩放固定，50 帧/秒、共 480 帧，时长 9.6 秒，最高支持 4096 × 4096，背景沿用以上设置。

    PNG / GIF 在后台导出，可继续预览和选点；退出软件会停止未完成的任务。透明 GIF 使用透明抖动保留半透明细节；选择颜色或图片背景可获得平滑的淡化效果。

    跨版本方块差异与映射
    
      
    
    
    
    
    
    不同 MC 版本间存在方块命名与状态差异（例如 1.21.9 的铁链 chain→iron_chain、1.20.3 的草 grass→short_grass 等）。您可以选择更改为目标版本映射，或按旧版原样保留。
    
    
    
      
      
    
    
    
    
    
    
    
    
    
      
      
    
    
      

  
    
    
      
    帮助与功能说明
    
      
    
    
    
    
      
    
        
    1. Minecraft 本地资源联动（MC联动）
    
        
    点击顶部栏目 MC联动 或「文件 → 关联 MC 版本文件夹…」，可导入任意 Minecraft 版本隔离目录（例如 .minecraft\versions\1.21.11-Fabric 0.18.4）或 .minecraft 根目录。
    
        
      
          
    • 目录校验：所选目录必须包含 resourcepacks 文件夹；软件会自动读取版本 JSON、客户端 JAR（获取精确版本与方块目录）、options.txt（识别游戏内已启用材质包及优先级）、mods（检测 Litematica）以及 schematics 文件夹。
      • 
          
    • 材质包与投影同步：支持在联动面板中一键同步 MC 已启用的 .zip / 文件夹材质包（注：.7z / .rar 需先解压为文件夹或转为 .zip），也可以直接浏览并一键渲染 schematics 文件夹中的 .litematic / .nbt / .schem 文件。
      • 
        
    
      
    
      
    
        
    2. 高低版本差异检测与映射选择
    
        
    渲染投影时，软件会自动比对投影的 MinecraftDataVersion、方块调色板与当前目标版本（未联动时为内置 26.3，联动后为所选 MC 版本）。当存在跨版本差异方块时，会弹出映射提示界面：
    
        
      
          
    • 常见跨版本差异示例：
            
      • 铁链：1.21.9 之前为 minecraft:chain，1.21.9+ 更名为 minecraft:iron_chain；
            
      • 矮草：1.20.3 之前为 minecraft:grass（1.12 为 tallgrass），1.20.3+ 更名为 minecraft:short_grass；
            
      • 草径 / 土径：1.17 之前为 minecraft:grass_path，1.17+ 更名为 minecraft:dirt_path；
            
      • 旧版告示牌：1.14 之前为 minecraft:sign / wall_sign，1.14+ 拆分为 oak_sign / oak_wall_sign；
            
      • 含水炼药锅与墙体属性：1.17 之前 cauldron[level=1..3] 拆分为 water_cauldron；1.16 之前墙体连接 true/false 升级为 low/tall/none。
          
      • 
          
    • 两种选择区别：
            
      • 更改映射（推荐）：将方块 ID 与属性转换为目标版本标准形式，材料清单、方块检查与三维模型均按目标版本展示；
            
      • 按旧版保留：保留投影原始方块 ID（如 minecraft:chain、minecraft:grass）；若导入了对应旧版材质包则优先使用旧版材质，否则借用兼容模型渲染，材料清单与状态检查仍保留原旧版 ID。
          
      • 
          
    • 若勾选「记住本次选择」，后续渲染将自动应用该策略；任何时候均可通过顶部 文件 → 跨版本方块映射… 或左侧投影信息栏的「映射设置…」重新修改或调出。
      • 
        
    
      
    
      
    
        
    3. 三维预览、导出与常用快捷键
    
        
      
          
    • 视角与漫游：预览区左/右键拖动旋转，滚轮缩放；按 V 进入第一人称飞行漫游，WASD + 空格 / Shift 移动，左键拾取方块状态与箱子/漏斗库存。
      • 
          
    • 选区与指令：按 B 启用选区/逐层查看；按 / 输入全局指令（如 /view、/search、/export）或 // 选区编辑指令（如 //set、//replace）。
      • 
          
    • 导出模式与可视化排版：工具栏开启「导出模式」可生成展示图 PNG 并自动复制剪贴板；点击顶部 设置 → 导出模式设置… 可直接预览并拖动调整图标、标题、全部投影保存信息、自定义插图、背景色与双视角角度；按 G 打开「更改投影」36 格背包与调试棒进行三维修改；点击顶部「二维搭建」进入平面红石微时序沙盒。
      •

    自定义按键
    点击右侧绑定，再按新键或滚动滚轮。左右 Shift、Ctrl、Alt 视为同一键；鼠标键也可绑定。
    视角：拖动鼠标旋转，滚轮缩放；更改投影中滚轮切换快捷栏物品，Alt＋滚轮缩放。漫游：移动鼠标转向。微调：按住设置的修饰键并滚动滚轮。
    
  
    支持的指令
    分为一级全局指令（/ 开头）与二级选区/编辑指令（// 开头）。支持 ↑/↓ 历史记录与 Tab 自动补全；省略坐标时选取准星所指方块或当前视角位置。

    二维搭建
    只模拟当前平面，适合局部红石与微时序实验。面外更新、随机刻、区块加载和三维投影联动尚未接入；复杂机器请在游戏中复核。
    熔炉、合成器、酿造台仅保存库存；生物和船没有 AI。上次画布会自动恢复，重要设计可另存 JSON。
    
  
    
    二维搭建
    
    
    二维 MC 时序
    
    
    微时序与待执行队列
    26.3 二维时序：元件同时运行，实体类可放置矿车、船和生物。右键打开容器或实体设置，Shift＋右键拖动方块。保留最近 2000 条记录，显示筛选后的最近 100 条。
    覆盖范围与二维约定
    只运算当前二维平面，面外不放置或移动方块；俯视为平面元件提供隐式地面支撑，朝上/下漏斗不作面外传输。生物和船保持静止、没有AI；矿车参与EU运动、铁轨与容器交互，压力板检测实体并保留手动输入。活塞采用原版推动反应及实体推挤。门类、陷阱箱人数信号、红石火把、树电和脚电已接入。熔炉/合成器/酿造台只保留库存。命令支持画布内setblock、fill、summon；完整命令、特殊弹射物效果、已接入二维水流、TNT 和爆炸冲量；完整燃烧、战利品与其他环境机制仍待扩展。随机刻和实验性红石不引入。
